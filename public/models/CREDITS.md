# Model credits

`mascot-owl.glb` — original procedural scholar owl created for Mật Mã Đa Giới with Blender 5.2.2; no downloaded third-party geometry or textures. Source: `assets-src/mascot-owl.py` and `.blend`. Vertex colors, 1,974 triangles, 116,820 bytes, rig and idle/walk/hop clips. Authoring assistance: Gemini via Antigravity, integrated and checked by Codex for the project owner.

Three.js r180 and GLTFLoader: existing MIT-licensed vendor distribution; see `/vendor/three/LICENSE`.
