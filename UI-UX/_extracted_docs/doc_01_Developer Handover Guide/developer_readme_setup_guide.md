# Giao An Dewey - Developer Handover Guide (Cline/VS Code)

This document provides setup instructions and technical specifications for implementing the **Giao An Dewey** platform redesign based on the "Xanh Dương Tri Thức" (Knowledge Blue) design system.

## 1. Project Stack Recommendation
To ensure optimal performance and maintainability, we recommend the following stack:
- **Framework:** Next.js 14+ (App Router) or React 18+.
- **Styling:** Tailwind CSS v3.x.
- **Icons:** Google Material Icons (Round preferred).
- **Charts:** Recharts or Chart.js (for Competency Reports).
- **Editor:** TipTap or Slate.js (for AI Co-pilot integration).

## 2. Environment Setup

### A. Tailwind Configuration
Add the following theme extensions to your `tailwind.config.js` to match the brand identity:

```javascript
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#3182ce',
        'surface-container-low': '#eff4ff',
        'outline-variant': '#ccdbf4',
        // Add other tokens from DESIGN_SYSTEM_2
      },
      fontFamily: {
        sans: ['Plus Jakarta Sans', 'Be Vietnam Pro', 'sans-serif'],
      },
      borderRadius: {
        'lg': '8px',
      }
    },
  },
  plugins: [
    require('@tailwindcss/typography'),
    require('@tailwindcss/forms'),
  ],
}
```

### B. Required Dependencies
Run the following to install the core UI and utility libraries:
```bash
npm install lucide-react recharts clsx tailwind-merge @tiptap/react @tiptap/starter-kit
```

## 4. Design Guidelines
- **Typography:** Maintain a base size of `16px` for readability. Use `Plus Jakarta Sans` for a modern, professional look.
- **Spacing:** Use a consistent 8px grid system (`p-2`, `p-4`, `p-8`).
- **Interactions:** Use subtle transitions (`duration-200`) for hover states on cards and buttons.
