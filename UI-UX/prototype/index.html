Hướng triển khai vào app chính

  • Trích xuất design tokens dùng chung: màu, font, radius, shadow, spacing.
  • Ưu tiên chuyển 3 màn hình trọng tâm: AI Co-pilot Editor, Smart Matrix Grid, Dashboard.
  • Chuẩn hóa component layout trước khi đưa từng workflow vào React để tránh xung đột với logic hiện hữu.
  • Giữ bản prototype này làm “visual source of truth” để QA so sánh sau khi migrate.

Điểm cần bổ sung

  • Đã cập nhật đủ 13/13 màn hình theo Master Handover sau khi bạn bổ sung zip mới.
  • Các đường dẫn iframe hiện trỏ theo đúng tên thư mục giải nén mới, có dấu tiếng Việt.
  • Cần kiểm tra responsive thực tế vì các mẫu Stitch chủ yếu là HTML tĩnh.
