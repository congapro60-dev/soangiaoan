## 1. Trục dữ liệu thực nghiệm xuyên suốt (Thematic Dataset)

**Kỹ thuật giải tích phân chứa tham số bằng hệ phương trình máy tính Casio:**
- Cho tích phân: $I = \int_1^2 \dfrac{3x + 1}{x^2 + x} dx = a \ln 2 + b \ln 3$ với $a, b \in \mathbb{Z}$.
- **Bước 1 (Tính và lưu tích phân):**
  - Bấm máy tính tính tích phân $I$: Bấm $\int_1^2 \dfrac{3x+1}{x^2+x} dx \approx 1{,}791759...$
  - Bấm gán vào biến: **STO -> A** (biến $A$ lưu giá trị đúng của $I$).
- **Bước 2 (Thiết lập phương trình):**
  - Ta có: $a \ln 2 + b \ln 3 = A \implies a = \dfrac{A - b \ln 3}{\ln 2}$.
- **Bước 3 (Dò bảng Table):**
  - Vào chế độ **Table** (Menu 8 trên fx-580VNX).
  - Nhập hàm: $f(x) = \dfrac{A - x \ln 3}{\ln 2}$ (ở đây $x$ đóng vai trò là số nguyên $b$).
  - Cho $x$ chạy từ $-5$ đến $5$, bước nhảy $1$.
  - Dò cột $f(x)$: Ta thấy ngay tại $x = 1$ ($b = 1$) thì $f(x) = 1$ ($a = 1$) là số nguyên đẹp!
- **Kết luận tức thì:** $a = 1, b = 1 \implies a + b = 2$ chỉ sau 30 giây bấm máy mà không cần tách phân thức đại số.

  - (C) Cả hai tham số

- **Câu hỏi thảo luận tiếp:**

### S3 · 480–960s · CÔNG CỤ TOÁN HỌC — Hệ thống 3 kỹ thuật tính nhanh siêu tốc
- **Bước 1:** Kỹ thuật 1 (Bảng D-I đa thức × mũ/lượng): Cột đạo hàm triệt tiêu về 0, cột nguyên hàm lặp, nhân chéo đan dấu.

- **Bước 3:** Kỹ thuật 3 (Hàm bù đối xứng): Nếu $f(x) + f(a + b - x) = k$ thì $\int_a^b f(x) dx = \dfrac{k(b - a)}{2}$.
- **Bước 4:** Kỹ thuật 4 (Kiểm tra đạo hàm 4 đáp án): Đạo hàm của đáp án tại điểm $x_0$ phải bằng giá trị hàm số dưới dấu tích phân tại $x_0$.
- **Câu hỏi dẫn (máy HS):**

### S4 · 960–1140s · PHÁT HIỆN LỖI SAI AI (AI Error of the Week)
- **Lời giải AI (chiếu màn hình):** "AI giải: Khi tính I = ∫_0^π cos(x) dx trên máy tính Casio, AI để màn hình ở chế độ DEG và bấm ra I ≈ 0,0548 rồi kết luận tích phân bằng 0,0548."
- **Nhiệm vụ HS:**
  1. Bắt lỗi: AI giải: Khi dùng máy tính tính tích phân I = ∫_0^π sin(2x) dx, AI để máy tính ở chế độ đo góc ĐỘ (Deg) và bấm ra kết quả sai lệch hoàn toàn.
  2. Bằng chứng: Sai lầm chí mạng khi bấm máy tích phân hàm lượng giác. Toàn bộ các công thức giải tích đạo hàm và tích phân lượng giác CHỈ ĐÚNG khi đơn vị góc là RADIAN (Rad). Để chế độ Deg máy tính sẽ tính sai hoàn toàn.
  3. Sửa: Quy tắc bắt buộc: Trước khi bấm tích phân hàm lượng giác, luôn bấm Shift -> Menu -> 2 -> 2 để chuyển máy tính về chế độ RADIAN (chữ R trên màn hình). Kết quả chuẩn: I = 0.
- **TeacherCue:** Nhắc khẩu quyết: "Giải tích lượng giác bắt buộc phải có chữ R trên màn hình".
- **LookFor:** HS kiểm tra chế độ Radian trên máy tính trước khi bấm.

### S6 · 1200–1620s · NHIỆM VỤ CÓ LỰA CHỌN — 3 luồng đều có hint
- **Luồng M (Must) — hint: chuyển máy sang Radian (Shift Menu 2 2); bấm phím tích phân; bấm STO A.**
1. Khi bấm tích phân hàm lượng giác trên máy tính, màn hình phải hiển thị chữ gì?
   - **Đáp án:** Phải hiển thị chữ R (chế độ Radian).
2. Nếu f(x) + f(6 - x) = 10 thì ∫_0^6 f(x) dx bằng bao nhiêu?
   - **Đáp án:** Bằng 10 · (6 - 0) / 2 = 30.

- **Luồng S (Should) — hint: dùng Table nhập f(x) = (A - x ln 3)/ln 2; Start -5, End 5, Step 1.**
1. Dùng bảng D-I tính tích phân I = ∫_0^1 x e^(2x) dx.
   - **Đáp án:** D: x -> 1 -> 0; I: e^(2x) -> e^(2x)/2 -> e^(2x)/4. I = [x e^(2x)/2 - e^(2x)/4]|_0^1 = (e²/2 - e²/4) - (0 - 1/4) = e²/4 + 1/4 = (e² + 1)/4.
2. Cho ∫_0^1 (2x + 1)/(x + 1) dx = a + b ln 2. Tìm a và b.
   - **Đáp án:** Tách tử: (2x+1)/(x+1) = 2 - 1/(x+1). Tích phân = (2x - ln|x+1|)|_0^1 = 2 - ln 2. Do đó a = 2, b = -1.

- **Luồng C (Could) — hint: nhận diện hàm bù f(x) + f(a+b-x) = k để ghi ngay kết quả k(b-a)/2.**
1. Cho I = ∫_0^1 \dfrac{x^3 + 2x}{x + 1} dx = a/b + c ln 2 với a/b tối giản. Tính a + b + c.
   - **Đáp án:** Chia đa thức: (x³ + 2x) : (x + 1) = x² - x + 3 dư -3. Tích phân = (x³/3 - x²/2 + 3x - 3 ln|x+1|)|_0^1 = (1/3 - 1/2 + 3) - 3 ln 2 = 17/6 - 3 ln 2. Vậy a = 17, b = 6, c = -3. Tổng a + b + c = 17 + 6 - 3 = 20.
2. Tính tích phân: I = ∫_0^2 \dfrac{x^{2026}}{x^{2026} + (2 - x)^{2026}} dx.
   - **Đáp án:** Hàm số thỏa mãn f(x) + f(2 - x) = 1 với a = 0, b = 2, k = 1. Theo công thức tính nhanh: I = 1 · (2 - 0) / 2 = 1.

- **LookFor:** HS M chuyển đúng Radian; HS S dò đúng Table; HS C áp dụng công thức hàm bù.

### S7 · 1620–1800s · POST-CHECK CÁ NHÂN & ĐÁNH GIÁ THƯỜNG XUYÊN
- **ĐGTX (máy HS):** Cho hàm số $f(x)$ liên tục thỏa mãn $f(x) + f(2 - x) = 4$. Tính $I = \int_0^2 f(x) dx$. → Áp dụng công thức tính nhanh hàm bù đối xứng: $I = \dfrac{k(b - a)}{2} = \dfrac{4(2 - 0)}{2} = 4$.
- **Câu hỏi bảng con (Đúng/Sai):**
  - "Tính tích phân lượng giác trên Casio bắt buộc để chế độ Radian (R)" → **Đúng**
  - "Nếu f(x) + f(a+b-x) = k thì ∫_a^b f(x) dx = k(b - a)/2" → **Đúng**
  - "Table chỉ tìm được khi a, b là số nguyên dương" → **Sai — tìm được cả số nguyên âm và phân số**
- **TeacherCue:** Đổi phiếu chấm chéo, kiểm tra áp dụng công thức tính nhanh ra 4.

### S8 · 1800–2100s · KIỂM TRA NHANH (QUICK-CHECK)
