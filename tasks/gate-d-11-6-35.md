## 1. Trục dữ liệu thực nghiệm xuyên suốt (Thematic Dataset)

**Tình huống: Bảng kiểm tra nhanh bốn dạng phương trình lượng giác dùng cho phòng điều khiển.**

| Dạng | Công thức | Chu kỳ | Điều kiện |
|---|---|---|---|
| $\sin x = m$ | $\alpha + 2k\pi$; $\pi - \alpha + 2k\pi$ | $2k\pi$ | $|m| \le 1$ |
| $\cos x = m$ | $\pm\alpha + 2k\pi$ | $2k\pi$ | $|m| \le 1$ |
| $\tan x = m$ | $\arctan m + k\pi$ | $k\pi$ | $x \ne \tfrac{\pi}{2} + k\pi$ |
| $\cot x = m$ | $\operatorname{arccot} m + k\pi$ | $k\pi$ | $x \ne k\pi$ |

- **Kiểm chứng tay:** $2\sin x - \sqrt3 = 0 \Rightarrow \sin x = \tfrac{\sqrt3}{2} \Rightarrow x = \tfrac{\pi}{3} + 2k\pi$ hoặc $\tfrac{2\pi}{3} + 2k\pi$.
- $\tan 2x = 1 \Rightarrow x = \tfrac{\pi}{8} + \tfrac{k\pi}{2}$.
- $\cot\dfrac{x}{2} = -1 \Rightarrow \dfrac{x}{2} = -\tfrac{\pi}{4} + k\pi \Rightarrow x = -\tfrac{\pi}{2} + 2k\pi$.

**Bẫy của bài:** nhầm chu kỳ; quên điều kiện xác định; quên hệ số khi biến là $2x$, $x/2$.

### S1 · 180–300s · KHỞI ĐỘNG — Bảng bốn dạng
- **Tình huống:** Bốn dạng phương trình với công thức, chu kỳ và điều kiện như bảng.
- **Câu hỏi tương tác (máy HS) — có 3 lựa chọn:**
  - *Phương trình $2\sin x - \sqrt3 = 0$ thuộc dạng nào và nghiệm là gì?*
  - (A) sin x = √3/2 → x = π/3 + 2kπ hoặc 2π/3 + 2kπ
  - (B) sin x = √3 → vô nghiệm
  - (C) tan x = √3 → x = π/3 + kπ
  - **Correct: (A)** — Chuyển vế: sin x = √3/2 (thỏa |m| ≤ 1) rồi dùng công thức sin.
- **Câu hỏi thảo luận tiếp:**
  1. `[PHÁT HIỆN]` Vì sao không phải vô nghiệm?
  2. `[SO SÁNH]` Dạng nào có điều kiện xác định?
- **TeacherCue (lớp yếu):** Treo bảng bốn dạng; HS chỉ dòng tương ứng trước khi giải.
- **LookFor:** HS biến đổi về dạng cơ bản trước khi tra công thức.

### S2 · 300–420s · XÁC ĐỊNH MỤC TIÊU — M / S / C
- **Must:** Nhận dạng và giải đúng phương trình lượng giác cơ bản ở dạng đơn giản.
- **Should:** Biến đổi phương trình về dạng cơ bản, xử lý hệ số của biến và lọc nghiệm.
- **Could:** Lập bảng tra bốn dạng; phản biện lời giải sai chu kỳ hoặc sai điều kiện.
- **Student:** chọn mức cam kết trên máy (chỉ để GV điều nhịp, không xếp loại).
- **Câu hỏi trọng tâm treo suốt tiết:** "Làm thế nào nhận ra dạng phương trình chỉ trong vài giây?"

### S3 · 420–780s · CÔNG CỤ TOÁN HỌC — Quy trình 4 bước cho mọi dạng
- **Bước 1:** Biến đổi về dạng cơ bản: $\sin x = m$, $\cos x = m$, $\tan x = m$, $\cot x = m$.
- **Bước 2:** Kiểm điều kiện: $|m| \le 1$ với sin/cos; điều kiện xác định với tan/cot.
- **Bước 3:** Áp công thức nghiệm đúng chu kỳ, chú ý hệ số của biến.
- **Bước 4:** Lọc nghiệm theo khoảng và kiểm một giá trị cụ thể.
- **Câu hỏi dẫn (máy HS):**
  1. `[SUY LUẬN]` Với $\tan 2x$, chu kỳ của $x$ là bao nhiêu?
  2. `[PHÁT HIỆN]` $\cot(x/2) = -1$ cho nghiệm nào?
- **TeacherCue (lớp yếu):** Khung 4 bước; nhắc HS yếu luôn viết hệ số biến ra trước khi chia.
- **Chốt:** Mọi phương trình lượng giác đều quy về bốn dạng cơ bản — khác nhau ở chu kỳ và điều kiện.

### S4 · 1080–1320s · PHÁT HIỆN LỖI SAI AI (AI Error of the Week)
- **Lời giải AI (chiếu màn hình):** "AI giải: "tan 2x = 1 ⇒ 2x = π/4 + kπ ⇒ x = π/4 + kπ. Vậy nghiệm là x = π/4 + kπ.""
- **Nhiệm vụ HS:**
  1. Bắt lỗi: AI giải $\tan 2x = 1$ ra $x = \tfrac{\pi}{4} + k\pi$ (quên chia chu kỳ và hệ số).
  2. Bằng chứng: $2x = \tfrac{\pi}{4} + k\pi \Rightarrow x = \tfrac{\pi}{8} + \tfrac{k\pi}{2}$; kiểm $x = \tfrac{\pi}{8}$: $\tan\tfrac{\pi}{4} = 1$ ✓.
  3. Sửa: $x = \tfrac{\pi}{8} + \tfrac{k\pi}{2}$.
- **TeacherCue:** Cho HS thay $x = \pi/8$ và $x = \pi/8 + \pi/2$ để thấy cả hai đều đúng.
- **LookFor:** HS kiểm bằng cách thay giá trị cụ thể.

### S5 · 1320–1500s · HƯỚNG DẪN PHÂN LUỒNG (M / S / C)
- GV hướng dẫn HS chọn phiếu M / S / C trên thiết bị và đọc kỹ hint trước khi làm.
- **Hint từng luồng (không lộ đáp án):**
  - **M:** "đưa về dạng cơ bản, rồi tra bảng."
  - **S:** "xử lý hệ số của biến, nhớ chia chu kỳ."
  - **C:** "lọc nghiệm và kiểm bằng máy tính."

### S6 · 1620–2040s · NHIỆM VỤ CÓ LỰA CHỌN — 3 luồng đều có hint
- **Luồng M (Must) — hint: đưa về dạng cơ bản, rồi tra bảng.**
1. Giải sin x = √3/2.
   - **Đáp án:** x = π/3 + 2kπ hoặc x = 2π/3 + 2kπ.
2. Giải tan x = √3.
   - **Đáp án:** x = π/3 + kπ, điều kiện x ≠ π/2 + kπ.

- **Luồng S (Should) — hint: xử lý hệ số của biến, nhớ chia chu kỳ.**
1. Giải cos(2x − π/4) = −1/2.
   - **Đáp án:** 2x − π/4 = ±2π/3 + 2kπ ⇒ 2x = π/4 ± 2π/3 + 2kπ ⇒ x = π/8 ± π/3 + kπ.
2. Giải cot(x/2) = −1.
   - **Đáp án:** x/2 = −π/4 + kπ ⇒ x = −π/2 + 2kπ.

- **Luồng C (Could) — hint: lọc nghiệm và kiểm bằng máy tính.**
1. Giải 2cos²x − 1 = 0.
   - **Đáp án:** cos²x = 1/2 ⇒ cos x = ±√2/2. Với cos x = √2/2: x = ±π/4 + 2kπ; với cos x = −√2/2: x = ±3π/4 + 2kπ. Gộp: x = π/4 + kπ/2.
2. Tìm nghiệm của tan x = 1 trong [0; π).
   - **Đáp án:** x = π/4 + kπ; trong [0; π) chỉ có x = π/4 (k = 0).

- **LookFor:** HS M đúng dạng; HS S đúng hệ số; HS C lọc đúng.

### S7 · 1620–2040s · POST-CHECK CÁ NHÂN & ĐÁNH GIÁ THƯỜNG XUYÊN
- **ĐGTX (máy HS):** Giải $\cot\dfrac{x}{2} = -1$. → $\dfrac{x}{2} = -\tfrac{\pi}{4} + k\pi \Rightarrow x = -\tfrac{\pi}{2} + 2k\pi$, điều kiện $x \ne 2k\pi$ (tương đương $\tfrac{x}{2} \ne k\pi$).
- **Câu hỏi bảng con (Đúng/Sai):**
  - "tan 2x = 1 ⇒ x = π/4 + kπ" → **Sai — phải chia hệ số**
  - "cot x = m có chu kỳ kπ" → **Đúng**
  - "sin x = √3/2 có 2 họ nghiệm" → **Đúng**
- **TeacherCue:** Chấm chéo theo bảng 4 dạng.

### S8 · 2040–2160s · KIỂM TRA NHANH (QUICK-CHECK)
- **Câu 1:** Vì sao tan 2x = 1 phải chia chu kỳ? → Vì sau khi có 2x = π/4 + kπ, chia hai vế cho 2 thì chu kỳ thành kπ/2.
- **Câu 2:** Dạng nào cần điều kiện xác định? → tan (cos x ≠ 0) và cot (sin x ≠ 0).
- **Chốt nhanh:** Về dạng cơ bản — kiểm điều kiện — đúng chu kỳ — lọc nghiệm.

### S9 · 2160–2340s · ỨNG DỤNG THỰC TẾ — Bảng tra dùng trong phòng điều khiển
- sin/cos: chỉ giải được khi |m| ≤ 1 — ngoài ra ghi "vô nghiệm".
- tan/cot: luôn giải được nhưng phải loại điểm không xác định.
- Mọi kết quả phải kiểm bằng cách thay một giá trị cụ thể.
- **TeacherCue:** Hỏi: "Nếu bảng tra ghi thiếu điều kiện xác định thì hậu quả gì?"
