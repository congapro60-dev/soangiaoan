## 1. Trục dữ liệu thực nghiệm xuyên suốt (Thematic Dataset)

**Mô hình tính điện lượng phóng qua tụ điện biến thiên:**
- Cường độ dòng điện nạp vào tụ điện giảm theo thời gian:
  $$i(t) = \dfrac{2t}{(t^2 + 1)^2} \quad (\text{ampe}, t \ge 0).$$
- Điện lượng tích lũy $q(t) = \int i(t) dt = \int \dfrac{2t}{(t^2 + 1)^2} dt$.
- Nhận xét vi phân: $(t^2 + 1)' = 2t \implies d(t^2 + 1) = 2t dt$.
- **Đổi biến số:** Đặt $u = t^2 + 1 \implies du = 2t dt$.
- Nguyên hàm chuyển thành:
  $$\int \dfrac{du}{u^2} = \int u^{-2} du = -\dfrac{1}{u} + C = -\dfrac{1}{t^2 + 1} + C.$$
- Điều kiện ban đầu $q(0) = 0 \implies -1 + C = 0 \implies C = 1$.
- Hàm điện tích nạp theo thời gian: $q(t) = 1 - \dfrac{1}{t^2 + 1}$ (coulomb). Khi $t \to +\infty$, $q(t) \to 1$ C (điện lượng bão hòa).

### S1 · 180–300s · KHỞI ĐỘNG — Điện lượng nạp theo thời gian t
- **Tình huống:** Biểu thức nguyên hàm ∫ [2t / (t² + 1)²] dt với đạo hàm của mẫu (t² + 1)' = 2t xuất hiện ở tử.
- **Câu hỏi tương tác (máy HS) — có 3 lựa chọn:**
  - *Nếu đặt u = t² + 1 thì nguyên hàm trở thành biểu thức nào?*
  - (A) ∫ u⁻² du = -1/u + C
  - (B) ∫ u² du = u³/3 + C
  - (C) ∫ (1/u) du = ln|u| + C
  - **Correct: (A)** — Vì 2t dt = du nên nguyên hàm là ∫ (1/u²) du = ∫ u⁻² du = -1/u + C = -1/(t² + 1) + C.
- **Câu hỏi thảo luận tiếp:**
  1. `[PHÁT HIỆN]` Tại sao không đặt u = t²?
  2. `[SO SÁNH]` Phép đổi biến số và vi phân nhảy bước có gì khác nhau?
- **TeacherCue (lớp yếu):** Khoanh tròn cụm đạo hàm 2t dt và cụm biểu thức u = t² + 1.
- **LookFor:** HS nhận ra sự khớp nối giữa 2t dt và du.

### S2 · 300–480s · XÁC ĐỊNH MỤC TIÊU — M / S / C
- **Must:** Nhận diện đúng dạng vi phân u'(x)dx = du để chọn ẩn phụ u = u(x); tính nguyên hàm ∫ f(u(x))u'(x)dx = F(u(x)) + C.
- **Should:** Thành thạo các phép đổi biến chứa căn thức (đặt u = √...), chứa hàm mũ (đặt u = e^x), và hàm lượng giác.
- **Could:** Biến đổi vi phân trực tiếp (nhảy vi phân) mà không cần viết tường minh bước đặt ẩn phụ.
- **Student:** chọn mức cam kết trên máy (chỉ để GV điều nhịp, không xếp loại).
- **Câu hỏi trọng tâm treo suốt tiết:** "Dấu hiệu nhận biết rõ nhất để chọn ẩn phụ u trong biểu thức tích dưới dấu nguyên hàm là gì?"

### S3 · 480–960s · CÔNG CỤ TOÁN HỌC — Quy trình 3 bước đổi biến số nguyên hàm
- **Bước 1:** Bước 1: Chọn ẩn phụ $u = u(x)$ thích hợp (chứa căn, biểu thức dưới mẫu, hoặc trong hàm hợp $f(u)$).
- **Bước 2:** Bước 2: Tính vi phân $du = u'(x) dx$ và biểu diễn toàn bộ tích phân theo biến $u$ và $du$.
- **Bước 3:** Bước 3: Tìm nguyên hàm theo biến $u$: $\int f(u) du = F(u) + C$, sau đó trả lại biến cũ $x$: $F(u(x)) + C$.
- **Câu hỏi dẫn (máy HS):**
  1. `[SUY LUẬN]` Trong biểu thức ∫ (ln x / x) dx, ta nên đặt u bằng gì?
  2. `[PHÁT HIỆN]` Nếu sau khi đổi biến mà vẫn còn sót biến x thì phải xử lý ra sao?
- **TeacherCue (lớp yếu):** Bảng các cặp đổi biến kinh điển: (f(x), f'(x)dx); (√u, u = căn); (ln x, dx/x); (e^x, e^x dx).
- **Chốt:** Đặt u sao cho du = u'(x)dx hấp thụ toàn bộ phần biến x còn lại trong biểu thức.

### S4 · 960–1140s · PHÁT HIỆN LỖI SAI AI (AI Error of the Week)
- **Lời giải AI (chiếu màn hình):** "AI viết: Tính ∫ (2x + 1)⁴ dx. AI đặt u = 2x + 1 => du = dx. Do đó ∫ u⁴ du = u⁵/5 + C = (2x + 1)⁵/5 + C."
- **Nhiệm vụ HS:**
  1. Bắt lỗi: AI giải: Tính ∫ 2x√(x² + 1) dx. AI đặt u = x² + 1 => du = 2x dx. AI tính nguyên hàm ra: (2/3) u^(3/2) + C rồi dừng lại kết luận.
  2. Bằng chứng: Quên bước trả về biến x ban đầu. Kết quả của bài toán nguyên hàm theo biến x bắt buộc phải là một hàm số theo x, không thể để ẩn phụ u.
  3. Sửa: Phải thay lại u = x² + 1: Kết quả cuối cùng là (2/3) (x² + 1)√(x² + 1) + C.
- **TeacherCue:** Ghi nhớ: "Đổi biến thì phải trả biến".
- **LookFor:** HS chỉ ra lỗi chưa trả biến u về biến x.

### S5 · 1140–1200s · HƯỚNG DẪN PHÂN LUỒNG (M / S / C)
- GV hướng dẫn HS chọn phiếu M / S / C trên thiết bị và đọc kỹ hint trước khi làm.
- **Hint từng luồng (không lộ đáp án):**
  - **M:** "đặt u là biểu thức trong căn hoặc trong ngoặc lũy thừa; tính vi phân du."
  - **S:** "nhớ rút gọn hệ số tự do trước khi tra bảng nguyên hàm cơ bản."
  - **C:** "với căn bậc hai u = √g(x) thì bình phương u² = g(x) rồi lấy vi phân 2u du = g'(x)dx để khử căn hoàn toàn."

### S6 · 1200–1620s · NHIỆM VỤ CÓ LỰA CHỌN — 3 luồng đều có hint
- **Luồng M (Must) — hint: đặt u là biểu thức trong căn hoặc trong ngoặc lũy thừa; tính vi phân du.**
1. Tính vi phân du khi đặt u = 3x - 1.
   - **Đáp án:** du = 3 dx.
2. Biểu thức (cos x dx) là vi phân của hàm số lượng giác nào?
   - **Đáp án:** Là vi phân của sin x (d(sin x) = cos x dx).

- **Luồng S (Should) — hint: nhớ rút gọn hệ số tự do trước khi tra bảng nguyên hàm cơ bản.**
1. Tính nguyên hàm: I = ∫ (2x + 1) e^(x² + x) dx.
   - **Đáp án:** Đặt u = x² + x => du = (2x + 1)dx. I = ∫ e^u du = e^u + C = e^(x² + x) + C.
2. Tính nguyên hàm: I = ∫ sin² x cos x dx.
   - **Đáp án:** Đặt u = sin x => du = cos x dx. I = ∫ u² du = u³/3 + C = (sin³ x)/3 + C.

- **Luồng C (Could) — hint: với căn bậc hai u = √g(x) thì bình phương u² = g(x) rồi lấy vi phân 2u du = g'(x)dx để khử căn hoàn toàn.**
1. Tính nguyên hàm: I = ∫ [1 / (x ln² x)] dx.
   - **Đáp án:** Đặt u = ln x => du = dx/x. I = ∫ (1/u²) du = -1/u + C = -1/(ln x) + C.
2. Tính nguyên hàm: I = ∫ [x³ / √(x² + 1)] dx.
   - **Đáp án:** Đặt u = √(x² + 1) => u² = x² + 1 => x² = u² - 1 và x dx = u du. I = ∫ [(u² - 1) u du / u] = ∫ (u² - 1) du = u³/3 - u + C = [(x² + 1)√(x² + 1)]/3 - √(x² + 1) + C.

- **LookFor:** HS M đặt đúng u; HS S tính đúng vi phân; HS C trả lại biến x chính xác.

### S7 · 1620–1800s · POST-CHECK CÁ NHÂN & ĐÁNH GIÁ THƯỜNG XUYÊN
- **ĐGTX (máy HS):** Tính nguyên hàm: $I = \int \dfrac{\ln x}{x} dx$. → Đặt $u = \ln x \implies du = \dfrac{1}{x} dx$. Nguyên hàm: $\int u du = \dfrac{u^2}{2} + C = \dfrac{\ln^2 x}{2} + C$.
- **Câu hỏi bảng con (Đúng/Sai):**
  - "Nguyên hàm đổi biến số phải trả lại biến x ban đầu" → **Đúng**
  - "∫ (1/x) ln x dx = ln²(x) + C" → **Sai — thiếu hệ số 1/2**
  - "Đặt u = √x thì vi phân du = dx / (2√x)" → **Đúng**
- **TeacherCue:** Đổi phiếu chấm chéo, kiểm tra hệ số 1/2 ở ln² x.

### S8 · 1800–2100s · KIỂM TRA NHANH (QUICK-CHECK)
- **Câu 1:** Nếu đặt ẩn phụ mà biểu thức vẫn còn chứa cả x và u thì nguyên hàm có tính được không? → Chưa tính được, phải biểu diễn nốt phần x còn lại theo u hoặc chọn cách đổi biến khác.
- **Câu 2:** Có bao nhiêu cách tính nguyên hàm ∫ sin x cos x dx? → Có 3 cách: đặt u = sin x ra (sin² x)/2; đặt u = cos x ra -(cos² x)/2; hoặc dùng góc nhân đôi (1/2) sin 2x ra -(cos 2x)/4 (các kết quả sai khác nhau một hằng số C).
- **Chốt nhanh:** Chọn u -> Tính du = u'dx -> Đổi toàn bộ sang biến u -> Tìm nguyên hàm -> Trả lại biến x.
