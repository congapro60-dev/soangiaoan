## 1. Trục dữ liệu thực nghiệm xuyên suốt (Thematic Dataset)

**Tình huống: Hai nhánh bài tập của chương III, cùng một quy trình nhận dạng → chọn chiến lược → giải → kiểm → phản tư.**

**Nhánh A — tam giác:** $b = 6$, $c = 8$, $A = 60^\circ$.
- $a^2 = 36 + 64 - 48 = 52 \Rightarrow a = 2\sqrt{13} \approx 7{,}21$.
- $S = \tfrac12\cdot6\cdot8\cdot\sin60^\circ = 12\sqrt3 \approx 20{,}78$.
- Kiểm: $|8 - 6| = 2 < 7{,}21 < 14$ ✓; $S \le \tfrac12\cdot6\cdot8 = 24$ ✓.

**Nhánh B — miền nghiệm:** $x \ge 0$, $y \ge 0$, $x + y \le 2$.
- Điểm nguyên: $(0;0)$, $(1;0)$, $(2;0)$, $(0;1)$, $(1;1)$, $(0;2)$.
- Đỉnh: $(0;0)$, $(2;0)$, $(0;2)$.

**Nhánh C — ngược:** $a = 13$, $b = 14$, $c = 15$, $S = 84$ → $R = \dfrac{13\cdot14\cdot15}{4\cdot84} = 8{,}125$.

**Bẫy của bài:** không kiểm sau khi giải; quên điều kiện nguyên; nhầm $R$ với $2R$.

### S1 · 180–300s · KHỞI ĐỘNG — Chọn nhánh và cam kết
- **Tình huống:** Ba nhánh A (tam giác), B (miền nghiệm), C (bài ngược tìm R).
- **Câu hỏi tương tác (máy HS) — có 3 lựa chọn:**
  - *Sau khi tính được a = 2√13, phép kiểm nào phù hợp nhất?*
  - (A) Không cần kiểm vì đã dùng đúng định lý
  - (B) Kiểm bằng bất đẳng thức tam giác |b − c| < a < b + c
  - (C) Kiểm bằng cách tính lại lần hai
  - **Correct: (B)** — Bất đẳng thức tam giác là phép kiểm độc lập với công thức đã dùng; tính lại lần hai dễ lặp cùng một lỗi.
- **Câu hỏi thảo luận tiếp:**
  1. `[PHÁT HIỆN]` Điểm nguyên nào nằm trên biên của x + y ≤ 2?

- **TeacherCue (lớp yếu):** Treo quy trình 5 bước; HS chọn nhánh và ghi cam kết.

### S3 · 420–780s · CÔNG CỤ TOÁN HỌC — Quy trình 5 bước và chữa mẫu

- **Bước 4:** Kiểm bằng phép độc lập: bất đẳng thức tam giác, cận diện tích, thay điểm vào hệ.

- **TeacherCue (lớp yếu):** Khung 5 bước; nhắc bước 4 và 5 là phần lớn HS bỏ qua.
- **Chốt:** Giải đúng chỉ là nửa bài; kiểm và phản tư mới khép kín quy trình.

### S4 · 1080–1320s · PHÁT HIỆN LỖI SAI AI (AI Error of the Week)
- **Lời giải AI (chiếu màn hình):** "AI giải: "Tam giác có a = 13, b = 14, c = 15 và diện tích S = 84. Áp dụng định lý sin: a/sin A = R, và vì S = ½bc·sin A nên sin A = 2S/(bc) = 168/210 = 0,8. Suy ra R = a/sin A = 13/0,8 = 16,25.""
- **Nhiệm vụ HS:**
  1. Bắt lỗi: AI kết luận $R = 16{,}25$ vì dùng $a/\sin A = R$ thay vì $2R$.
  2. Bằng chứng: Định lý sin cho $a/\sin A = 2R$; với $a = 13, b = 14, c = 15, S = 84$ thì $R = 8{,}125$, không phải $16{,}25$.
  3. Sửa: Chia đôi kết quả: $R = 8{,}125$ m; kiểm bằng $S = abc/(4R) = 2730/32{,}5 = 84$ ✓.
- **TeacherCue:** Cho HS kiểm ngược bằng công thức diện tích để thấy R = 8,125 mới đúng.
- **LookFor:** HS dùng phép kiểm ngược thay vì tin kết quả.

### S5 · 1320–1500s · HƯỚNG DẪN PHÂN LUỒNG (M / S / C)

### S6 · 1620–2040s · NHIỆM VỤ CÓ LỰA CHỌN — 3 luồng đều có hint
- **Luồng M (Must) — hint: làm nhánh B trước vì ngắn; nhớ liệt kê điểm nguyên.**
1. Với tam giác b = 3, c = 4, A = 90°, viết công thức tính a và S.
   - **Đáp án:** a² = b² + c² − 2bc·cos A (với A = 90° thì cos = 0 nên a² = 25); S = ½·b·c·sin A = 6.
2. Với hệ x ≥ 0, y ≥ 0, x + y ≤ 2, điểm (1; 1) có là nghiệm không?
   - **Đáp án:** Có: 1 ≥ 0, 1 ≥ 0, 1 + 1 = 2 ≤ 2 (nằm trên biên).

- **Luồng S (Should) — hint: làm nhánh A, kiểm bằng bất đẳng thức tam giác và cận S.**
1. Cho tam giác b = 6, c = 8, A = 60°. Tính a và S.
   - **Đáp án:** a² = 52 ⇒ a = 2√13 ≈ 7,21; S = ½·6·8·sin60° = 12√3 ≈ 20,78.
2. Tìm các đỉnh miền nghiệm x + y ≤ 4, x ≥ 1, y ≥ 0.
   - **Đáp án:** (1;0), (4;0), (1;3) — kiểm: 1 + 3 = 4 ≤ 4.

- **Luồng C (Could) — hint: làm nhánh C và kiểm ngược bằng S = abc/(4R).**
1. Với x + y ≤ 12, x ≥ 4, y ≥ 0 và P = 2x + 3y, so sánh P tại (4;8) và (12;0).
   - **Đáp án:** P(4;8) = 8 + 24 = 32; P(12;0) = 24. Theo P, (4;8) tốt hơn.
2. Cho tam giác a = 13, b = 14, c = 15 và S = 84. Tính bán kính ngoại tiếp R rồi kiểm tra bằng công thức diện tích.
   - **Đáp án:** R = abc/(4S) = (13·14·15)/(4·84) = 2730/336 = 8,125. Kiểm ngược: abc/(4R) = 2730/32,5 = 84 = S ✓.

- **LookFor:** HS M đủ điểm nguyên; HS S có 2 phép kiểm; HS C kiểm ngược đúng.

### S7 · 1620–2040s · POST-CHECK CÁ NHÂN & ĐÁNH GIÁ THƯỜNG XUYÊN
- **ĐGTX (máy HS):** Với $a = 13$, $b = 14$, $c = 15$ và $S = 84$, tính $R$ và kiểm lại. → $R = abc/(4S) = 2730/336 = 8{,}125$. Kiểm ngược: $abc/(4R) = 2730/32{,}5 = 84 = S$ ✓.
- **Câu hỏi bảng con (Đúng/Sai):**
  - "a/sin A = R" → **Sai — phải bằng 2R**
  - "S ≤ ½bc" → **Đúng**
  - "Điểm nguyên phải thỏa mọi điều kiện" → **Đúng**
- **TeacherCue:** Chấm chéo bài theo 5 bước.

### S8 · 2040–2160s · KIỂM TRA NHANH (QUICK-CHECK)
- **Câu 1:** Vì sao không nên làm tròn a = 2√13 ngay từ đầu? → Vì các bước sau (diện tích, kiểm bất đẳng thức) có thể tích luỹ sai số; giữ căn đến kết luận rồi mới làm tròn.
- **Câu 2:** Nêu một phép kiểm cho kết quả R. → Thay R vào S = abc/(4R) và so với diện tích đã biết; nếu khớp thì R đúng.
- **Chốt nhanh:** Nhận dạng → chiến lược → giải → kiểm → phản tư.
