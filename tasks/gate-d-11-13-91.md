## 1. Trục dữ liệu thực nghiệm xuyên suốt (Thematic Dataset)

**Bảng phân loại chiến lược tính giới hạn dãy số:**
1. **Dạng phân thức hữu tỉ $\dfrac{P(n)}{Q(n)}$ (dạng $\dfrac{\infty}{\infty}$):**
   - Chia cả tử và mẫu cho $n^k$ với $k$ là bậc cao nhất của mẫu.
   - Bậc tử = Bậc mẫu $\implies$ Giới hạn = Tỉ số hệ số cao nhất.
   - Bậc tử < Bậc mẫu $\implies$ Giới hạn = $0$.
   - Bậc tử > Bậc mẫu $\implies$ Giới hạn = $\pm\infty$.
2. **Dạng vô định căn thức $\infty - \infty$:**
   - Ví dụ: $\lim [\sqrt{n^2 + 2n} - n]$. Hai hệ số bậc cao nhất bằng nhau ($1 = 1$) $\implies$ **Bắt buộc nhân lượng liên hợp**:
     $$\sqrt{n^2 + 2n} - n = \dfrac{n^2 + 2n - n^2}{\sqrt{n^2 + 2n} + n} = \dfrac{2n}{n(\sqrt{1 + 2/n} + 1)} = \dfrac{2}{\sqrt{1 + 2/n} + 1} \to 1.$$
   - Nếu hai hệ số khác nhau (ví dụ $\sqrt{4n^2 + 1} - n$) $\implies$ Chỉ cần rút $n$ ra ngoài: $n(\sqrt{4 + 1/n^2} - 1) \to +\infty$.

### S1 · 180–300s · KHỞI ĐỘNG — Khi nào bắt buộc nhân liên hợp?
- **Tình huống:** Xét hai biểu thức: A = √(n² + 2n) - n và B = √(4n² + 1) - n khi n -> +∞.
- **Câu hỏi tương tác (máy HS) — có 3 lựa chọn:**
  - *Biểu thức nào BẮT BUỘC phải nhân lượng liên hợp để khử dạng vô định?*
  - (A) Biểu thức A (hệ số bậc cao nhất triệt tiêu nhau: 1 - 1 = 0)
  - (B) Biểu thức B
  - (C) Cả hai biểu thức
  - **Correct: (A)** — Ở biểu thức A: √(n²) - n = n - n = 0 (bậc cao nhất triệt tiêu) nên bắt buộc nhân liên hợp; ở B hệ số là 2 - 1 = 1 > 0 nên chỉ cần rút n ra ngoài.
- **Câu hỏi thảo luận tiếp:**
  1. `[PHÁT HIỆN]` Dấu hiệu nhận biết nhanh khi nào phải nhân liên hợp?
  2. `[SO SÁNH]` Biểu thức √(n² + 1) - √(n² + n) có phải nhân liên hợp không?
- **TeacherCue (lớp yếu):** So sánh hệ số của n ở hai căn thức bậc hai.
- **LookFor:** HS nhận diện hệ số bậc 1 triệt tiêu thì phải nhân liên hợp.

### S2 · 300–480s · XÁC ĐỊNH MỤC TIÊU — M / S / C

### S3 · 480–960s · CÔNG CỤ TOÁN HỌC — Hệ thống 3 kỹ thuật khử dạng vô định
- **Bước 1:** Kỹ thuật 1: Chia cho lũy thừa cao nhất của mẫu (áp dụng cho phân thức đại số và biểu thức mũ $a^n$).
- **Bước 2:** Kỹ thuật 2: Nhân lượng liên hợp: $(\sqrt A - \sqrt B)(\sqrt A + \sqrt B) = A - B$ (khi hệ số cao nhất triệt tiêu).
- **Bước 3:** Kỹ thuật 3: Định lý kẹp: Nếu $v_n \le u_n \le w_n$ và $\lim v_n = \lim w_n = L$ thì $\lim u_n = L$.
- **Câu hỏi dẫn (máy HS):**
  1. `[SUY LUẬN]` Lượng liên hợp của ∛A - ∛B là gì?
  2. `[PHÁT HIỆN]` Biểu thức 3^n và 2^n thì cơ số nào chi phối giới hạn?
- **TeacherCue (lớp yếu):** Bảng công thức các hằng đẳng thức liên hợp bậc 2 và bậc 3.
- **Chốt:** Khử vô định bằng cách chuyển phép trừ thành phép chia qua hằng đẳng thức liên hợp.

### S4 · 960–1140s · PHÁT HIỆN LỖI SAI AI (AI Error of the Week)
- **Lời giải AI (chiếu màn hình):** "AI viết: Tính lim [√(n² + 4n) - n]. Rút n ra ngoài: lim n [√(1 + 4/n) - 1] = lim n · (1 - 1) = lim n · 0 = 0."
- **Nhiệm vụ HS:**
  1. Bắt lỗi: AI giải: Tính lim (3·2^n - 4^n) / (2·4^n + 1). AI chia cả tử và mẫu cho 2^n được kết quả vô cực.
  2. Bằng chứng: Với biểu thức chứa hàm số mũ a^n, phải chia cho cơ số LỚN NHẤT ở mẫu là 4^n, không chia cho cơ số nhỏ hơn 2^n.
  3. Sửa: Chia cả tử và mẫu cho 4^n: lim [ 3·(2/4)^n - 1 ] / [ 2 + (1/4)^n ] = [ 3·0 - 1 ] / [ 2 + 0 ] = -1/2.
- **TeacherCue:** Nhắc lại: chia cho cơ số lớn nhất để các lũy thừa còn lại có |q| < 1 tiến về 0.
- **LookFor:** HS chọn đúng cơ số lớn nhất 4^n.

### S6 · 1200–1620s · NHIỆM VỤ CÓ LỰA CHỌN — 3 luồng đều có hint
- **Luồng M (Must) — hint: chọn cơ số lớn nhất để chia; thay các số hạng (q)^n bằng 0 khi |q| < 1.**
1. Tính lim (2n + 3)/(5n - 1).
   - **Đáp án:** Chia cho n: lim (2 + 3/n)/(5 - 1/n) = 2/5.
2. Biểu thức liên hợp của (√n - 1) là gì?
   - **Đáp án:** Là (√n + 1).

- **Luồng S (Should) — hint: nhân liên hợp tử và mẫu: nhân thêm (√A + B) và chia lại cho chính (√A + B).**
1. Tính giới hạn: lim (3n² - 1)/(n³ + 2).
   - **Đáp án:** Bậc tử (2) < bậc mẫu (3) -> giới hạn bằng 0.
2. Tính giới hạn: lim [√(n² + 1) - n].
   - **Đáp án:** Nhân liên hợp: lim 1/[√(n² + 1) + n] = 0.

- **Luồng C (Could) — hint: tách thêm bớt số hạng thích hợp khi gặp biểu thức vừa chứa căn bậc hai vừa căn bậc ba.**
1. Tính giới hạn: lim [√(n² + n + 1) - √(n² - n)].
   - **Đáp án:** Nhân liên hợp: lim [(n² + n + 1 - n² + n)] / [√(n² + n + 1) + √(n² - n)] = lim (2n + 1) / [n(√(1 + 1/n + 1/n²) + √(1 - 1/n))] = 2 / (1 + 1) = 1.
2. Tính giới hạn: lim [sin(n!) / n].
   - **Đáp án:** Ta có |sin(n!)| ≤ 1 nên -1/n ≤ sin(n!)/n ≤ 1/n. Vì lim(-1/n) = lim(1/n) = 0 nên theo định lý kẹp, giới hạn bằng 0.

- **LookFor:** HS M chia đúng cơ số; HS S nhân liên hợp đúng; HS C thêm bớt chuẩn xác.

### S7 · 1620–1800s · POST-CHECK CÁ NHÂN & ĐÁNH GIÁ THƯỜNG XUYÊN
- **ĐGTX (máy HS):** Tính giới hạn: $\lim [\sqrt{n^2 + 6n} - n]$. → Nhân liên hợp: $\lim \dfrac{n^2 + 6n - n^2}{\sqrt{n^2 + 6n} + n} = \lim \dfrac{6n}{n(\sqrt{1 + 6/n} + 1)} = \dfrac{6}{1 + 1} = 3$.
- **Câu hỏi bảng con (Đúng/Sai):**
  - \"Biểu thức mũ chia cho cơ số lớn nhất ở mẫu\" → **Đúng**
  - \"lim [√(n² + 4) - n] = 0\" → **Đúng (nhân liên hợp ra 4/(2n) -> 0)**
  - \"lim (3^n / 2^n) = 0\" → **Sai — bằng +∞ vì (3/2)^n có cơ số 1,5 > 1**
- **TeacherCue:** Đổi phiếu chấm chéo, chú ý rút gọn phân số 6/(1+1) = 3.

### S8 · 1800–2100s · KIỂM TRA NHANH (QUICK-CHECK)

- **Câu 2:** Tại sao không nhân liên hợp khi tính lim [√(4n² + 1) - n]? → Vì hệ số bậc 1 là √4 - 1 = 1 ≠ 0, không phải dạng vô định triệt tiêu; chỉ cần rút n ra ngoài là xong.
- **Chốt nhanh:** Phân thức: chia bậc cao nhất mẫu; Căn thức triệt tiêu: nhân liên hợp; Mũ: chia cơ số lớn nhất.
